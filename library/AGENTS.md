# 대본 작성 규칙

이 폴더는 앱의 대본 라이브러리다. 앱은 대본을 노래방 자막처럼 한 문장씩 흘려 보여주고, 사용자는 따라 읽으며 연습한다.
사용자는 주로 한국어를 쓰는 영어 학습자이고, 북미에서 생활하거나 일하려는 사람이 많다.
목표는 실생활의 거의 모든 상황에서 바로 꺼내 연습할 수 있는 대본 라이브러리다.

파일 형식은 저장소 루트 AGENTS.md의 "대본 파일 형식"을 따른다. id 형식은 `<분야 단어>-<상황>[-레벨]` (예: transport-taxi-wrong-address-b1).

dialogue 예시

```
> Good morning, Riverside Clinic. How can I help you?

Hi, I'd like to book an appointment with Dr. Patel, please.

> Sure. Are you a current patient here?

Yes, I am. My last visit was in the spring.
```

## 작성 기준

- 실제 원어민이 그 상황에서 하는 말. 교과서식 문장 금지("I am fine, thank you, and you?" 같은 것).
- 축약형(I'm, don't, we'll)과 자연스러운 완충 표현(Actually, Just to check, Sorry, could you)을 쓴다.
- 한 문장 25단어 이하. 대본 하나 2~4분 분량.
- 같은 상황이라도 수준이 다르면 별도 대본. 어휘와 문장 구조가 실제로 달라야 한다.
  - A2: 짧은 문장, 기본 어휘
  - B1: 이유와 조건 설명
  - B2: 협상, 의견, 완곡한 거절
  - C1: 뉘앙스, 관용 표현, 긴 설명
- 권장 wpm: A2 110, B1 130, B2 150, C1 170.
- dialogue는 실제처럼 예상 밖 전개를 넣는다(예약이 꽉 참, 서류가 부족함, 상대가 잘못 알아들음). 사용자가 되묻고 정정하는 대사가 연습 가치가 크다.
- 모두 새로 쓴 글. 영화 대사, 드라마, TED 자막, 기사, 교재 예문 금지.
- 시험명(CELPIP, IELTS, TOEFL, TOEIC), 실제 인물명, 실제 회사·병원·은행·브랜드 이름 금지. 가상 이름 사용.
- 의료, 법률, 금융, 응급 대본은 대화 연습용이다. 약 이름과 용량, 법 조항, 실제 수수료와 금리처럼 사실 정보로 읽힐 내용은 넣지 않는다.
- region은 나라마다 제도가 달라지는 상황만 CA 또는 US로 지정한다.
- 이름은 다양한 문화권에서 고르되, 특정 집단을 고정관념으로 그리지 않는다.

- ※ 안내문은 03-health, 04-money-admin, 12-emergency 분야에만 넣는다. 문구는 '※ 대화 연습용 가상 상황입니다. 실제 절차와 비용은 해당 기관에 확인하세요.' 다른 분야에는 넣지 않는다.

## 작업 방식

- 시작할 때 library/ 폴더와 library/index.json을 읽어 이미 있는 id와 하위 상황을 확인한다. 중복을 만들지 않는다.
- 요청된 분야에서 아직 다루지 않은 하위 상황을 우선한다.
- 수준 분포 기본값(10개 기준): A2 3, B1 4, B2 2, C1 1. 실생활 분야는 dialogue 위주.
- 파일은 library/<category>/<id>.md 경로에 만든다.
- npm run lint:library 와 npm run build:library 를 실행한다. 오류는 고쳐서 통과시킨다. 경고는 고칠 수 있으면 고치고, 남긴 경고는 이유를 적는다.
- 앱 코드와 tools/는 수정하지 않는다. 형식 규칙이 맞지 않는다고 판단하면 수정하지 말고 PR 설명에 제안한다.

## PR 설명 형식 (배치 하나 = PR 하나)

- 이번 배치 목록 표: id / 하위 상황 / type / level / 분량
- lint 출력의 분야별·수준별 집계 표
- 남긴 경고와 이유
