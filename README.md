# Karaoke Reader

영어 대본의 현재 문장을 화면에 고정하고 WPM에 맞춰 단어를 채우는 읽기·말하기 연습 도구입니다.

## 현재 범위

프로그램 작업 단계 2까지 구현했습니다. 기존 단일 HTML을 분리하고 미국식 IPA 사전 빌드를 추가했습니다. 프레임워크와 번들러를 사용하지 않습니다.

- `index.html`: 문서 구조와 화면
- `assets/app.css`: 기존 스타일과 운영체제 설정에 따른 라이트·다크 테마
- `assets/app.js`: 재생, 문장 분할, 파일 불러오기, 단축키, 발음 표시
- `assets/i18n.ko.js`: 한국어 UI 문구

## 로컬 실행

저장소 루트에서 Python 3으로 실행합니다.

```sh
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다. 별도 빌드는 필요하지 않습니다.

재생 버튼 또는 Space로 재생·일시정지하고, 대본 편집에서 텍스트를 입력하거나 `.txt`, `.md`, `.srt`, `.vtt`, `.docx`를 불러옵니다. `?` 버튼에서 단축키를 확인할 수 있습니다. 대본과 설정은 이 브라우저의 localStorage에 저장됩니다.

## 발음 사전 빌드

Node.js와 npm이 설치된 환경에서 저장소 루트에서 실행합니다. 검증 환경은 Node.js v26.13.0, npm 11.20.0입니다.

```sh
npm ci
npm run build:ipa
```

`cmu-pronouncing-dictionary` 3.0.0을 개발 의존성으로 고정하고, 대체 발음 항목(`(숫자)` 접미사)을 제외한 126,046개 단어를 `data/ipa-en-us.json`에 생성합니다. 음절 구분 점과 강세 표시는 제공된 변환 로직을 그대로 사용합니다.

- `regression`: `rə.ˈɡrɛ.ʃən`
- `minute`: `ˈmɪ.nət`

생성 파일을 저장소에 포함하므로 앱을 로컬 서버로 실행할 때 빌드할 필요는 없습니다. 빌드 시 네트워크 접근은 npm 의존성 설치에만 필요합니다. 사전 라이선스는 `NOTICE.md`에 기록했습니다.

## 현재 제약과 후속 단계

앱의 발음 표시 기능은 아직 루트의 `ipa.json`을 요청하지만 빌드 산출물은 `data/ipa-en-us.json`입니다. 단계 2는 사전 빌드에 한정하며, 앱 요청 경로 연결은 단계 3의 다운로드 확인·진행률·재시도·삭제와 함께 진행합니다. 현재 앱에서 발음 표시를 켜면 사전 요청이 실패합니다. 캐시·오프라인, 라이브러리, 모바일 개선, GitHub Pages 배포도 후속 단계입니다.

기존 Google Fonts 요청과 `.docx`를 처음 불러올 때 사용하는 Mammoth CDN 요청은 유지했습니다. 서버·로그인·분석 스크립트는 없습니다. 파일 처리는 브라우저에서 수행합니다.
